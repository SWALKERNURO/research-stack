# v0.1.0 — Initial Public Research Release

Nurowerx Research Stack connects TRACE provenance, LOOP evaluation/correction, LENS visualization and FRAME research workspaces. This release contains the complete existing application, release fixes, NRS-Bench 1.0.0, three technical reports, original fixtures, actual screenshots and reproducibility instructions.

Local fresh-install validation passed 54 tests (35 backend, 12 visualization, 7 browser), reproduced the reference semantic digest and executed three seeds/18 controlled evaluations. Full-split results per seed were 10/60 for first-match, 60/60 for evidence-aware and 30/60 after reviewed prefer-latest. The affected case was 1/1, reported separately. The historical 31-test baseline is preserved independently. Exact commit, CI, scans and clone verification are indexed in docs/validation.

Fixes include atomic graph exchange, idempotent import, duplicate-judgment rejection, packaged migrations, allowed-host validation, missing-value/interval/gap rendering and an actual JSON report preview. Release artifacts include source, Python API wheel/sdist, dataset and research archives plus SHA256SUMS.txt. Use the source archive for the complete application; the wheel does not contain the compiled frontend.

These are deterministic synthetic software-validation results, not a real-model benchmark or human study. SQLite is the validated storage target; hard interruptions require manual investigation; shared access tokens are not per-user authorization. No independent-party reproduction, peer review or unissued DOI is claimed. Zenodo metadata is ready, but local browser automation failed before account access. Follow research/archive/README.md to finish archiving when access is available.
